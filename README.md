# 血壓日記 Blood Pressure Diary

一個用來記錄每天早晚血壓的行事曆 App。純前端（HTML / CSS / JavaScript），不需要建置步驟，可以直接用 GitHub Pages 部署，也能「加入主畫面」當成 App 使用（支援離線）。

## 功能

- **日曆記錄**：每天以扁平色塊顯示當日血壓分級，小圓點標示早上 / 晚上是否已量測；點選日期可查看、編輯當天所有記錄。
- **兩種輸入方式**：
  - **拍照辨識**：對準血壓計螢幕，App 會自動辨識收縮壓、舒張壓、脈搏三排數字（連續多次結果一致才採用），確認後填入；也可以從相簿選照片。
  - **手動輸入**：輸入三個數字，輸入完會自動跳到下一格並即時顯示血壓分級。
  - App 會記住你上次選的方式。
- **iPhone 鬧鐘風格滾輪**：上午/下午、時、分三欄滾輪選擇記錄時間（可循環滾動），另有「現在 / 早上 7:00 / 晚上 9:00」快捷鍵。
- **早晚提醒**：首頁標語提醒每天至少早晚各量一次，並顯示連續完成天數；量超過兩次也都可以記錄。
- **趨勢圖**：X 軸為日期，Y 軸預設為「收縮壓 · 當日最高」，可自由切換：
  - **Y 軸數值**：收縮壓（高壓）、舒張壓（低壓）、收縮＋舒張、脈搏、平均血壓 MAP、脈壓差
  - **每日取值**：當日最高、當日平均、當日最低、只看早上、只看晚上
  - **期間**：7 天、30 天、90 天、全部
  - 附統計方塊（平均 / 最高 / 最低 / 記錄天數）、目標虛線、觸控十字準線與數據表
- **深淺色主題**：右上角一鍵切換，或在設定中選擇「跟隨系統」。
- **備份與換手機**：設定頁的「匯出所有記錄」會產生備份檔（手機上可直接分享到「檔案」、雲端硬碟、LINE、AirDrop）；新手機按「匯入備份檔」即可還原。匯入是「合併」，不會刪除或覆蓋現有資料，重複的記錄會自動略過。也支援匯入本 App 匯出的 CSV。
- 資料只存在本機瀏覽器（localStorage），照片辨識也完全在手機上進行，不會上傳。

## 拍照辨識的原理

血壓計的數字是「七段顯示器」，所以用一個很小的模型就能辨識：

1. 把對準框內的影像縮小成寬 320 像素的灰階圖，用 Sauvola 自適應二值化（能抵抗反光與陰影）。
2. 找出連通區塊、去掉螢幕外框，把同一個數字的筆畫合併成候選框。
3. 每個候選框縮放成 16×24 的小圖，交給一個 **int8 量化的小型神經網路（385→48→11，約 19k 參數、27 KB）** 判斷是 0–9 還是「不是數字」。
4. 依位置與字的大小找出「收縮壓 / 舒張壓 / 脈搏」三列（脈搏的字比較小），並補回常被漏掉的百位數「1」。

模型是用合成的液晶螢幕影像訓練的（各種字型粗細、傾斜、殘影、反光、模糊、雜訊、整台機器入鏡），訓練工具在 `tools/`：

```bash
python3 -m http.server 8765 &                     # 在專案根目錄
node tools/build-dataset.js /tmp/bp-data 24000    # 產生訓練資料（需要 playwright）
python3 tools/train.py /tmp/bp-data js/digit-model.js
```

> 辨識結果一定會先讓使用者確認，數字有誤可以直接修改。

## 部署到 GitHub Pages

1. 到 repository 的 **Settings → Pages**
2. **Source** 選 **Deploy from a branch**
3. Branch 選 **main**，資料夾選 **/ (root)**，按 **Save**
4. 稍等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`

## 本機預覽

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 檔案結構

```
index.html            主頁面
css/style.css         樣式（淺色 / 深色色票）
js/app.js             畫面與互動邏輯
js/store.js           資料儲存、日期工具、血壓分級
js/wheel.js           iPhone 風格滾輪選擇器
js/chart.js           SVG 趨勢圖
js/camera.js          相機畫面、對準框、相簿照片
js/ocr.js             七段顯示器數字辨識流程
js/digit-model.js     數字辨識小模型（自動產生）
tools/                合成訓練資料與訓練程式
sw.js                 離線快取（Service Worker）
manifest.webmanifest  PWA 設定
icons/                App 圖示
```

## 血壓分級參考

依 2022 台灣高血壓治療指引（居家血壓）：正常 < 120/80、偏高 120–129/< 80、第一期 130–139 或 80–89、第二期 ≥ 140 或 ≥ 90。居家血壓控制目標 < 130/80 mmHg。

> 本 App 僅供記錄參考，不能取代醫師診斷。
