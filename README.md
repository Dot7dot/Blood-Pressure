# 血壓日記 Blood Pressure Diary

一個用來記錄每天早晚血壓的行事曆 App。純前端（HTML / CSS / JavaScript），不需要建置步驟，可以直接用 GitHub Pages 部署，也能「加入主畫面」當成 App 使用（支援離線）。

## 功能

- **日曆記錄**：每天以扁平色塊顯示當日血壓分級，小圓點標示早上 / 晚上是否已量測；點選日期可查看、編輯當天所有記錄。
- **快速新增**：輸入收縮壓、舒張壓、脈搏三個數字即可新增，輸入完會自動跳到下一格並即時顯示血壓分級。
- **iPhone 鬧鐘風格滾輪**：上午/下午、時、分三欄滾輪選擇記錄時間（可循環滾動），另有「現在 / 早上 7:00 / 晚上 9:00」快捷鍵。
- **早晚提醒**：首頁標語提醒每天至少早晚各量一次，並顯示連續完成天數；量超過兩次也都可以記錄。
- **趨勢圖**：X 軸為日期，Y 軸預設為「收縮壓 · 當日最高」，可自由切換：
  - **Y 軸數值**：收縮壓（高壓）、舒張壓（低壓）、收縮＋舒張、脈搏、平均血壓 MAP、脈壓差
  - **每日取值**：當日最高、當日平均、當日最低、只看早上、只看晚上
  - **期間**：7 天、30 天、90 天、全部
  - 附統計方塊（平均 / 最高 / 最低 / 記錄天數）、目標虛線、觸控十字準線與數據表
- **深淺色主題**：右上角一鍵切換，或在設定中選擇「跟隨系統」。
- **資料備份**：匯出 CSV（Excel 可開啟）、匯出 / 匯入 JSON 備份檔。資料只存在本機瀏覽器（localStorage），不會上傳。

## 部署到 GitHub Pages

1. 到 repository 的 **Settings → Pages**
2. **Source** 選 **Deploy from a branch**
3. Branch 選 **main**，資料夾選 **/ (root)**，按 **Save**
4. 稍等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`

## 本機預覽

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 檔案結構

```
index.html            主頁面
css/style.css         樣式（淺色 / 深色色票）
js/app.js             畫面與互動邏輯
js/store.js           資料儲存、日期工具、血壓分級
js/wheel.js           iPhone 風格滾輪選擇器
js/chart.js           SVG 趨勢圖
sw.js                 離線快取（Service Worker）
manifest.webmanifest  PWA 設定
icons/                App 圖示
```

## 血壓分級參考

依 2022 台灣高血壓治療指引（居家血壓）：正常 < 120/80、偏高 120–129/< 80、第一期 130–139 或 80–89、第二期 ≥ 140 或 ≥ 90。居家血壓控制目標 < 130/80 mmHg。

> 本 App 僅供記錄參考，不能取代醫師診斷。
